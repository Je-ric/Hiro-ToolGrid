LED Binary Clock

Each column of LEDs represents a digit in binary

Columns

H1 H2 — Hour tens & ones
M1 M2 — Minute tens & ones
S1 S2 — Second tens & ones

🟡 ON  ⚫ OFF

Add up the ON bit values per column to get the digit.
